# Cover sezione Libri

Convenzione nome file (stessa logica di `covers/manga/`):

- libro singolo: `libri_<slug-titolo>.jpg`
- serie / più volumi: `libri_<slug-titolo>_vol<N>.jpg`
- con edizione: `libri_<slug-titolo>_<slug-edizione>_vol<N>.jpg`

Lo slug è minuscolo, senza accenti, con `_` al posto di spazi e simboli; `&` diventa `and`.
Esempi: `libri_orfani_vol1.jpg`, `libri_aqualung_vol1.jpg`, `libri_il_cigno_nero.jpg`.

Titoli già spostati qui dai manga: Orfani (16 vol.), Aqualung (5 vol.).
